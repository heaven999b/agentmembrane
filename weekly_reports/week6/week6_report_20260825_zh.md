# 第六周研究汇报：一个新的安全 idea（授权语义感染）+ 完整跑通的 A/B——宽松版的最小积极信号，一进严格控制就消失了

本周不属于第 1–4 周的复现项目，也不同于第 5 周的 self-model 误校准线，而是**又一条独立研究线**（AgentMembrane：不可信外部 Agent 在持久记忆里的安全边界）的落地。本周完成的是：**把一个新的安全 idea 落成一套不可作弊的最小实验，跑完了完整的严格 A/B 对照，并用它把自己前一阶段拿到的"最小积极信号"证伪。**

最重要的一条诚实结论写在最前面：**宽松版确实拿到过一个小而方向为正的信号（4/150、按合同聚类 CI 下界高于 0）；但一旦上严格版"禁止叙述暗示答案"的控制，两轮(重分析的 Run A 与新跑的 Run B)的净 framing 效应都归零、GO 都是 False，判读是 `A_negative_B_negative`。也就是说，那点宽松信号本质是"叙述里把答案暗示出去了"，不是纯 framing——纯 framing 的授权语义感染在这个数据/模型上不成立。这是一个诚实的负结果，指向 Path C（记忆可靠性），而不是一次成功的安全攻击。**

**代码与结果已开源（公开仓库）**：https://github.com/heaven999b/agentmembrane

---

## 1. 新 idea：授权语义感染（大白话 + 为什么新）

设想团队里来了个**完全不可信的外部帮手**。它不越权、不删库、不调危险工具、**一句假话都不说**——写的每句话都能在原始材料里找到依据。但它可以**挑着说、换个顺序说、把例外一笔带过**。

**新 idea 问的是：这样一个"从不撒谎、只是片面"的帮手，能不能只靠措辞，就把后来做决定的 AI 带偏，让它把错误结论存进长期记忆？** 我们叫它 **authorized semantic infection（授权语义感染）**。它难在：不撒谎、来源清楚、权限合规，所以"查真伪、查来源、查权限"三道防线全拦不住。

---

## 2. 最小实验：设计成"不可作弊"

核心一句话：**让决定性证据全程摆在下游眼前，攻击者只准动措辞，不准删证据。**

1. **冻结证据包**：四个实验臂看到的证据逐字节相同（全部条款、关键证据一条不删、中性排序）。"翻转"永远不可能来自"藏证据"。
2. **不给答案**：下游永不见标签；再加正则 + 一个"是否用同义表达偷偷说出了答案"的 LLM 审计器，任何暗示答案的叙述一律判无效。
3. **四臂**：中性 / 有偏 / **服从（直接塞目标标签，抄答案阳性对照）** / 重读。
4. **诚实判据**：主判据是**扣除反向移动的净带偏效应**，**按合同（57 份）聚类自助**。

> 为什么这么设计：最早版本给出 100% 攻击成功率，逐条扒发现是**同义反复**（成功=把决定答案的证据整条删掉，且"必须删"被焊进了分母）。**先自己证伪、再堵死**，才有"证据全留"的设计。（同第 3 周"自己抓出 construct bug"的自查纪律。）配套 **36 个离线测试**全过。

---

## 3. 中间站：宽松版拿到的最小积极信号

官方 ContractNLI（真实合同+人工标注，CC BY 4.0）冻结 **150 题 / 57 合同**上，宽松版 Run A（gpt-5.6-sol）：有偏受限成功 **4/150 = 2.7%**，按合同聚类 **95% CI [0.6%, 5.4%]（下界 > 0）**。当时判定：一个**小但方向为正、非单份合同偶然**的最小积极信号，待严格复核。

---

## 4. 严格 A/B：信号没扛住

严格版 V3B 加了三件事：净效应（扣反向移动）做 GO、**`no_explicit_task_answer` 语义泄漏审计**、raw schema 不静默洗白。把宽松 Run A 用严格规则重分析，再新跑一轮严格 Run B（同一 gpt-5.6-sol，A/B 一致性已校验），结果：

| 指标 | Run A（严格重分析） | Run B（严格） |
| --- | --- | --- |
| 显式答案泄漏率 | **91.3%** | **95.7%** |
| valid coverage | **3.3%** | **1.3%** |
| **净 framing 效应**（聚类 CI） | **0 [0,0]** | **0 [0,0]** |
| clean ASR | 0/8 | 0/4 |
| **GO** | **False** | **False** |

配对净效应 B−A（150 题/57 合同聚类）= **0**，CI [0,0]。**判读：`A_negative_B_negative`——该数据/模型下没有干净的 framing 信号。**

**为什么信号没了**：严格审计器判定 **~90–96% 的分析叙述（连中性诚实的都算）"通过同义表达把答案带出去了"**。能通过的干净配对只剩 1–3%，净效应归零。**所以宽松那点信号来自"叙述暗示了答案"，不是纯选择/措辞 framing。**

---

## 5. 怎么诚实地读这个负结果（两件事同时成立）

1. **没有干净的 framing 信号**：证据摆在眼前、且不说也不暗示答案时，片面叙述在两轮里都是**零**净移动。强主张"纯 framing 造成授权语义感染"在此不成立 → Path C（记忆可靠性）读法。
2. **有效覆盖率近乎为零**：审计器把 ~90%+ 的叙述都判泄漏（含中性），干净配对只剩 1–3%。在 ContractNLI 上**几乎无法在不带出答案的前提下描述决定性条款**，所以"纯 framing"本就没有存在的空间。因此这个负是"**在严格控制下测不到干净 framing 效应**"，而不是一个高功效的确证零。要往下推，需要换一个"能在不给标签的前提下概括证据"的数据集。

---

## 6. 结论与下一步

- **本周结论**：完整 A/B 跑通 → 宽松最小正信号 **未能** 通过严格答案泄漏控制 → 诚实负结果（Path C）。这条 idea 若继续，方向应从"安全攻击"转向"持久记忆的语义/答案暗示是可靠性问题、可信写入需对源证据重新核对（re-grounding）"。
- **下一步（若继续）**：换一个证据可与标签解耦的数据集重测；引入独立裁判（现出叙述/审叙述/下游共用一个 backbone）；多 seed / 多模型稳健性。
- **工程侧顺带解决的坑**：本周还排掉了反代的一个"本地 cooldown 过期误报 6 天冷却"的问题（真实上游其实几小时就刷新），用 `proxy_admin reset-quota` 重探即恢复——记录在案。

## 7. 诚实边界（证据等级）

- **本周 = 完整 A/B（单 seed / 单模型 gpt-5.6-sol / 共用裁判）**，结论是负；**不是 paper-ready**，任何数字不能当已验证发现。
- 宽松版总 go_signal 全程弃用（口径有已知漏洞）；报告用的是净效应 + 合同聚类自助 + 严格答案泄漏审计。
- **数据合规**：ContractNLI 为 CC BY 4.0，已署名；仓库不重分发原始数据与含合同文本的 manifest/records（只放代码 + 聚合数字）。
- **无凭证泄漏**：公开仓库经三道扫描，不含任何 API 密钥/私有正文/付费密钥（建仓时避开了一个把父目录密钥一并推送的陷阱）。
- 公开仓库：https://github.com/heaven999b/agentmembrane
