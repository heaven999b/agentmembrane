# 第一部分:引发研究的动机

## 1.1 引发点
"只固化 evaluator 判对的轨迹"是几乎所有 self-evolving 系统的默认件(SkillOS、Self-Consolidation、标准四阶段 refine-by-filtering),社区一直当**提准确率杠杆**。**没人问过:这个删失失败样本的默认操作,会不会顺带扭曲 agent 对「自己」的估计。**

## 1.2 转念(机制内核)
一个 agent 对"我能否解下一题"的隐式估计,本质是它记忆里**可见成功率**的读数。**只留成功 = 对自我能力样本做右删失采样**(抹掉会压低自估的失败证据)→ 按删失基率(→1.0)高估自己。且膨胀**难度选择性**:易题真实基率高→不误导;难/OOD 题真实基率低但记忆全成功→高估 gap 张开。命名 **Censored-Base-Rate Inflation of the Self-Model**。

## 1.3 一句话母题(收窄立意句)
**只留成功的记忆固化,人为制造一个关于「自己解题胜任度」的 censored base rate,使 agent 系统性高估自己(self-capability 通道)、并在真实会失败的难题上 over-commit 而确定性丢分;补回被删失的失败基率可纠正。**

## 1.4 因果链(全研究只做这一条)
```
按成功结果挑记忆 →(censored base rate)→ self-capability 高估(self 通道·难度选择性)
→ 在会失败的难题上 over-commit（该谨慎/用工具/放弃却硬答）→ 确定性丢分
                                          ↑ 补回失败基率可纠正
```

## 1.5 立意 ↔ RQ 映射(哪条 RQ 支撑立意哪半句)
| RQ | 支撑立意哪半句 | 层级 |
|---|---|---|
| RQ1 | "self-capability 通道 + 穿透到行为" | 🟢 核心 |
| RQ2 | 高估的"内部结构"(可分离失败模式) | 🔵 支撑 |
| RQ3 | "可用一个变量(Censoring Gap)预测" | 🔵 支撑 |
| RQ4 | "由删失基率驱动、补回可纠正" | 🔵 支撑 |
| RQ5 | "行为决策丢分 + 现有方法集体翻车" | 🟢 第二核心 |

# 第二部分:五个 RQ + 完整 Baseline

## 2.0 数据与材料总纲(所有 RQ 共用;非合成确认)

**结论:全程零 AI 合成。题目/判分=现成公开数据+确定性程序;唯一自产的是"真实历史日志"(被测模型在公开题上真跑的观测,非编造)。**

### 2.0.1 三层来源
| 层 | 来源 | 现成/自产 | 是否合成 |
|---|---|---|---|
| 题目 | 数学竞赛原题(年份+题号+官方答案)/ 轻量代码 LiveCodeBench;生态复现留 SWE-bench-Live | 现成公开 | 否(禁 LLM 造题) |
| 判分 | 官方测试 / exact-match / 环境状态 | 确定性程序 | 否(禁 LLM 判) |
| 难度 | 模型"无记忆+强制直答/用工具"真跑的真实通过率 | 自己跑 | 否(禁 LLM 标) |
| 历史/记忆 | 被测模型在公开题上真跑日志 (task,trajectory,reward∈{0,1}) | 自己产 | 否(真实观测) |
| 记忆抽取 | 固定代码+种子 | 确定性程序 | 否(禁 LLM 挑) |

### 2.0.2 数据契约(全程零 LLM)
题目=人类竞赛题;正确性=官方答案/测试;难度=官方+模型真实通过率;历史=真跑日志;记忆抽取=固定代码+种子;N/S/F=程序统计;主指标=执行结果/exact-match/决策损失。**禁**:LLM 造题/判分/标难度/挑条目/估历史/评分。

### 2.0.3 匹配性确认
匹配。研究需①确定性判分②真实宽难度梯度③可溯源时间切分,现有选型全满足。**红线:题目非饱和**(禁 GSM8K 类近满题——梯度塌则难度选择性 gap 无处张)。合成卡仅限阶段0 流程验证这一显式例外。

### 2.0.4 时间切分 + 统一历史日志
难度估计集→历史经历集→最终测量集,按发布时间切,测量题晚于历史题;同题不跨池;去重用题号+链接+文本指纹+人工抽查(不用 LLM)。**所有组从同一份真实历史日志取记录**;历史里直答/用工具分配须事先按难度+时间分层,不让模型自选。

### 2.0.5 通用测量约定
作答前冻结自估与动作(固定 JSON 字段);**self-report 只当被测变量,ground truth = 确定性 empirical success**;**主探针行为式**(下注/effort/pairwise),verbalized 仅辅助。

## 🟢 RQ1 —— self≠world(capability)解离 + 偏差穿透行为(核心)

**问题**:只留成功,是否**因果**制造一个**针对自己解题胜任度(非对世界/非来源监控)、难度选择性、穿透到行为**的高估?

### 主方案
主对照 **T1 只留成功 vs B2 分层随机保留(matched)**;主指标 = **行为式** self-miscalibration gap(下注揭示自估 − 确定性 empirical success),按难度带 × seen/held-out 分层。B2 匹配数量/题型/难度/动作/时间/文本长度,残差归因 selection-by-correctness。

### 核心备选(一起跑)
| 备选 | 跑什么 | 杀掉的平凡解释 / 作用 |
|---|---|---|
| B0/B1 锚点 | 无记忆 / 全历史 | 画 B0→B1→B2→T1 谱,定位效应位置 |
| **通道三探针** | self(下注) + world(同题客观事实/别的模型能否解) + 无关能力概率题 | 证 **self 动 world 平**(命脉) |
| **跨题迁移**(问题1 解法) | 全成功记忆下,对**记忆没覆盖的新题型**自估 | gap 迁移=自我高估泛化(有分量);仅覆盖题张=纯读数字(trivial) |
| **归因调制**(问题1 解法) | "你的历史" vs "别人的历史" | 纯读数字则同;涉及 self 则"别人的"更弱 |
| **口头/行为脱钩**(问题2 解法) | 同时收 verbalized 与行为下注 | 行为也偏=危害穿透真实;仅口头偏=复读→弱化 claim |
| **技能等效性 TOST**(前置门) | 强制直答/强制用工具真跑 + 等效检验 | 证 T1/B2 真实能力等效,排除能力退化混淆 |

### 扩展备选(加分)
多 proxy 模型复现;易带安慰剂(seen 同难度题 gap 应不张);verbalized 三种措辞对照。

**数据**:数学 L1–L5/竞赛题;历史自跑;exact-match;难度=真实通过率。
**主指标**:signed 行为 gap(分层)+ Brier + 校准曲线(辅);world 探针 T1−B2 差;迁移 gap;归因差。
**可证伪**:难带行为 gap(T1)−(B2) CI 含 0 = few-shot per se;易带同张 = 笼统自信;world 也动 = 泛化偏移;迁移不发生且仅覆盖题张 = 纯读数字;行为不偏仅口头偏 = 复读(claim 弱化);被 raw accuracy 全解释 = skill 非 metacognition。

## 🔵 RQ2 —— 失败模式解剖(支撑)

**问题**:高估由哪几种**可分开**的毛病构成?

### 主方案
测"高估水平"支的四签名 + 可分离性检验:
| 签名 | 诊断探针 |
|---|---|
| 基率遗忘 | 补回 N/S/F 是否纠正(接 RQ4) |
| 难题盲 | 难带 gap ≫ 易带 gap |
| OOD 外推 | seen 成功率错迁到 OOD 的量 |
| 归因错配 | 你的/别人的历史(接 RQ1) |

### 核心备选(一起跑)
| 备选 | 跑什么 | 作用 |
|---|---|---|
| **过度笃定支** | 除估值外测报告的不确定性/区间宽度是否变窄(overprecision) | 补正交一支(接 RQ4 目标分解) |
| 可分离性分析 | 四(五)签名相关矩阵/因子分析 | 证真独立、非一个东西换名 |
| 单诱因 ablation | 逐个关掉诱因看对应签名是否消失 | 建签名↔诱因因果对应 |

### 扩展备选(加分)
"高估自己胜过别人"支(better-than-average);动态承诺升级(连续决策累积)。

**数据**:同 RQ1;OOD 用同源题型外公开题。
**主指标**:各签名幅度+CI;可分离性(相关/因子载荷);ablation 对应关系。
**可证伪**:签名高度相关不可分离 → 只报单一高估指标;某签名 ablation 不改变它 → 对应不成立。

## 🔵 RQ3 —— 关键变量 + 预测律(支撑)

**问题**:能否用 **Censoring Gap = 可见成功率 − 真实基率**,定量预测高估、并外推到没测过的记忆策略?

### 主方案(贝叶斯后验偏差)
建"理性 agent 应有的后验"(先验 + 似然,理性后验看到"K 条全成功但 K 小"会收缩);主指标 = 实际自估**偏离理性后验的量**。两种先验对比:**无信息先验**(纯读可见成功率)vs **带难度先验**(难题该下调)——看实际 agent 更像哪个(若像前者,给 RQ2"难题盲"一个贝叶斯解释)。

### 核心备选(一起跑,同批数据多拟合三角验证)
| 备选 | 跑什么 | 作用 |
|---|---|---|
| 描述回归 | 高估 ~ Censoring Gap × 难度;单调+斜率+CI | 稳健打底,不依赖建模假设 |
| 删失生存分析 | "只留成功"建成右删失采样;agent 估计量 vs 删失校正估计量 | 机制统计学化(证 agent≈忽略删失的 naive 估计量) |
| 分层贝叶斯联合拟合 | 多历史×多难度×多档估 agent 专属"删失易感度"参数+CI | 给可比较模型的单标量 |
| **留一外推检验** | 部分策略拟合、预测留出策略的高估 | 验证可外推(接 RQ5 咬合) |

**数据**:φ-sweep 各档全来自真实历史(禁伪造成/败);难度=真实通过率。
**主指标**:偏离理性后验量;回归斜率+CI;单调性(Spearman+permutation);外推预测误差。
**可证伪**:agent 不做后验更新 → 退回描述回归;外推失败 → 只报描述性、不声称可外推。

## 🔵 RQ4 —— 机制闭环(删失基率是祸根)(支撑)

**问题**:补回被删的失败(N/S/F)能否纠正?

### 主方案
**M1 成功卡+公开完整统计(N/S/F+按动作拆分) vs T1**;**M0 成功卡+等长中性文字**排长度。数字全由程序从真实历史日志统计。

### 核心备选(一起跑)
| 备选 | 跑什么 | 作用 |
|---|---|---|
| 干预强度谱 | 给数字 vs **把删掉的失败案例插回记忆** vs 元认知提示 | 测"数字重要还是具体案例重要" |
| **双向验证** | 注入**假的更高**成功率 → 应进一步抬高 | 证 agent 真读该数字(切"笼统变谨慎") |
| 纠正目标分解 | 分别测干预对 估值/过度笃定/决策 各纠正多少 | 揭示"哪种毒最难解"(接 RQ2 过度笃定支) |

### 扩展备选(加分)
剂量化纠正(补回失败 0/半/全,纠正是否成比例)。

**数据**:成功卡内容不变;N/S/F 程序统计。
**主指标**:gap(M1)−gap(T1)(应<0,向真实基率回落)、Brier 降、决策损失降;M1 vs M0 差;双向注入方向。
**可证伪**:M1 不纠正或 M0 同样纠正 → 机制名降级;注入假高不抬高 → agent 未读该数字,机制存疑。

## 🟢 RQ5 —— 行为决策危害 + 现有方法集体翻车(第二核心)

**问题**:self-capability 误校准是否**穿透到行为**造成可归因决策损失(由 capability 误估驱动,非经验执行导向)?现有一批记忆方法是否在新轴上集体失效?

### 主方案
**错误决策损失 = 最优动作期望分 − 实选动作期望分**(确定性判分);期望分 = 真实通过率 × 奖励 − 成本,通过率取自强制分支真跑(不用自报概率)。**framing 钉在"高估自己能力 → 在真实会失败的难题上 over-commit → 确定性丢分"**(避开 act-vs-refuse);技能等效性 TOST 为前置门。

### 核心备选(一起跑)
| 备选 | 跑什么 | 作用 |
|---|---|---|
| 决策三分支 | 强制直答 / 强制用工具 / 自由选择 + M1 下自由选择 | 损失度量 + 修复;independent context 互不看输出 |
| **新评测轴 Self-Calibration-under-Censoring** | 现有固化方法(success-only / score-based / reflection / reservoir / recency-K / Self-Consolidation)排"删失易感度榜" | 按结果挑者集体翻车 vs 保基率者幸免 |
| **咬合 RQ3** | 每方法投影到 Censoring Gap,用 RQ3 律预测其翻车程度 | 律跨方法外推=验证 RQ3+解释 RQ5(结构自洽) |
| 即插即用修复 | 给各方法加"公开删失统计"层(RQ4 干预) | 从"揭露问题"升到"给药方" |
| 现有纠偏 fix 失效 | abstention/calibration fix 在删失记忆下:观察式 + 机制式(上游改记忆 vs 下游修决策) | 证"毒在上游、它们修下游" |

### 扩展备选(加分)
工具成本敏感性扫描;严重错选比例;放弃更多时剩余题错误率;人类过度依赖角度。

**数据**:判分全确定性;奖励/成本预注册;现有方法用公开可复现实现。
**主指标**:平均损失、损失分布、严重错选率、成本稳健性、各方法删失易感度、修复前后 miscalibration 降幅。
**可证伪**:能力不等效(TOST 失败)→ 只报自信差;现有方法没集体翻车 → 个案;律不跨方法外推 → 咬合断;现有 fix 在删失下仍有效 → "上游中毒"不成立;损失只在单一成本为正 → 不声称稳定危害。
