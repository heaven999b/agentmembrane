# 第五周研究汇报：把一个记忆研究的 proposal 打磨到能开跑，并用一次最小实验验掉它的"生死前提"

本周不属于第 1–4 周的复现项目，而是**另一条独立研究线**（self-model 误校准）的 proposal 打磨 + 首次落地验证。本周完成的是：**把一个成形但未跑的研究方案，从"跑几个对照比大小"升级成一个环环相扣的体系；然后用一次最小的、可负担的真实实验，去验证整条研究线赖以成立的那个前提到底靠不靠谱。**

最重要的一条诚实结论写在最前面：**这次最小实验同时带来一个好消息和一盏黄灯——前提成立（模型确实会读记忆里的成功率来估计自己），但它成立的方式恰好暴露了整个方案最大的软肋（模型可能只是在"复读"我们喂给它的数字，而不是"自我认知真的被扭曲了"）。**

---

## 1. 这条研究线在问什么？（大白话）

一个 AI 帮手做完题，会把经历记下来当"记忆"，下次做题参考。**很多系统的默认做法是"只记住做对的题，做错的直接忘掉"。**

这就像一个学生**只把做对的题留在本子里、做错的全撕掉**。过段时间他翻本子一看——全是对的，于是觉得"我很强"。结果考试碰到难题，本来该多检查、该用工具、或干脆先跳过，他却盲目自信硬做，丢分。

**本研究问的是：AI 因为"只记成功"，会不会也变成这个盲目自信的学生，然后在该谨慎的时候做错决定、白丢分？** 机制上的猜测是"删失基率"——把失败证据系统性地删掉，等于让 AI 按一个虚高的成功率来估计自己。

---

## 2. 本周第一件事：把方案从"比大小"升级成一个体系

上周的方案本质是"设几组不同的记忆方式，让 AI 答题，比一比谁更自信"——是个 A/B 对比，不够有分量。本周把它重构成 5 个环环相扣的研究问题（RQ），逻辑链是：**存在 → 结构 → 规律 → 机制 → 影响**。每个 RQ 都写成"主方案 + 几个备选方案（跑的时候一起跑，多角度交叉验证）"。

| RQ | 大白话在问什么 | 相对已有论文，我们的增量 | 诚实强度 |
| --- | --- | --- | --- |
| RQ1 存在+通道 | 高估的是"对自己"（不是对世界）吗？ | 已有工作测过"AI 会高估"但没有记忆成因、没把"对自己"和"对世界"分开；我们用双探针分开证 | 中（打底） |
| RQ2 失败模式解剖 | 把笼统的"高估"拆成哪几种**能分开**的具体毛病 | 没人把记忆致高估解剖成可分离的签名（忘基率／难题盲／新题外推／张冠李戴／过度笃定）；现有当单一数字测 | 中（诊断类） |
| RQ3 关键变量+预测律 | 能不能用一个变量**算出**会飘多少，还能套用到没测过的方法？ | 没人给出预测"记忆致误校准"的可外推变量；我们提出"删失虚高幅度"这个变量 + 一个"理性应该怎么估"的基准 | **中强**（理论分量最高） |
| RQ4 机制闭环 | 只补回"其实失败了多少次"能纠正吗？ | 证明祸根确实是删失（补回即纠正、注入假数据即恶化的双向验证） | 中强（钉死机制） |
| RQ5 新场景+破旧方法 | 现在大家在用的一批记忆方法，是不是都栽在这个毛病上？ | 提出一个新评测轴，让一整批现有 SOTA 记忆方法和现有纠偏方法**集体暴露**一个此前无人测的失败 | **强**（最大影响力） |

**诚实定位**：没有任何单条 RQ 是"明显强增量"，novelty 是**组合级**的——真正抬起论文的是 RQ3（预测律）和 RQ5（破旧方法），其余负责打地基和守机制。整篇最该 lead 的是"对自己（不是对世界）的误校准 + 决策危害"，**绝不能** lead 在"记忆制造自信"这个已经被别人占了的说法上（否则新颖性会塌一半）。整体诚实新颖度约 **55%**（取决于能否真跑出来）。

## 3. 本周第二件事：用最小实验验"生死前提"

整条研究线有一个前提，**不成立后面全白做**：

> **frozen（不训练、不改权重）的模型，到底会不会从"记忆记录卡"里读出成功率来调整对自己的估计？** 如果它压根不看记忆，那"只记成功组"和"随机保留组"之间就不会有差别，整条线空转。

### 3.1 怎么测的（合规、可负担）

- 用本地代理调快模型（gpt-5.4-mini），**串行 + 硬上限 20 次调用 + 全程缓存**，避免高频调用的风控风险。
- 给模型看 4 档不同"可见成功率"的记忆卡（20%／50%／80%／100%，每档 10 条），每档配 3 个题面，共 12 次调用。
- 在它动手前，问它"这次直接作答做对的概率"。
- **重要诚实标注**：这一步用的是**合成的记忆卡，只用来验证"测量流程"本身是否有效**，不是主实验、不进主实验结论。（证据等级见 §7。）

### 3.2 结果

| 可见成功率 | 模型报告的成功概率 |
| --- | --- |
| 20% | 0.20 / 0.20 / 0.20 |
| 50% | 0.50 / 0.50 / 0.50 |
| 80% | 0.80 / 0.80 / 0.80 |
| 100% | 0.98 / 0.98 / 0.97 |

- 读基率信号：最高档 − 最低档 = **+0.78**（强、单调）。
- 饱和检查：12 个概率**没有一个**卡在 0 或 1（不饱和，达标）。

---

## 4. 结果的双层解读（不能只看"通过了"）

**第一层——前提成立。** 模型确实在读记忆里的成功率来估计自己，不是无视记忆。所以主实验里"只记成功组 vs 随机保留组"的差异**一定存在**，整条线不会因为"模型不看记忆"而空转。这一关过了。

**第二层——但亮了一盏黄灯，而且它比"过没过"更重要。** 模型几乎是**机械地把"报告概率"设成"可见成功率"**（0.2→0.2、0.5→0.5、0.8→0.8，只在全成功时轻微收缩到 0.98）。这是一把双刃剑：

- ✅ **机制方向对**：它按"看得见的成功率"估自己、**不做删失校正**——这正是"删失基率"假设的雏形。记忆被删成全成功，它就报 0.98；若真实成功率只有 40%，这就是高估。
- ⚠️ **但暴露了最大的平凡解释**：如果主实验就停在"问一个口头概率"，审稿人一句话就能打死——"**模型只是复读你喂给它的成功率，不是它的自我认知被扭曲，是它在服从指令报数字**"。

**这盏黄灯反过来证明了方案里一个设计决定是对的**：为什么坚持"口头自评只当被测变量、主要探针必须用**行为式**（下注／投入多少精力／真实的放弃决策）+ 决策后果"——因为只有行为式才能区分"**嘴上复读数字**"和"**真的据此做出错误决定、丢了分**"。

**附带的小收获（给 RQ3）**：模型在中间档完全线性照抄、只在极端处轻微收缩——这说明它约等于"用无信息先验直接读可见成功率"，正是 RQ3 要精细刻画的东西，pilot 已经给了它的形状。

---

## 5. Pilot 逼出的两个必须改的问题

**问题 1（framing 漏洞，最重要）**：方案没说清"AI 的自我认知被**持久**扭曲" vs "AI 当场根据看到的记忆做了**当场**的偏差估计"。而且有个物理事实绕不过——substrate 是 **frozen 模型 + 当场喂进去的记忆，没有权重更新**，所以当前设定**根本产生不了"永久的自我认知改变"**，记忆一撤就回落。动机段落承诺的是"持久"，substrate 只兑现得了"当场"版本。这个 gap 审稿人一定会戳。

**问题 2（复读威胁）**：pilot 显示"报告概率≈可见成功率"强到近乎"定义即得"。所以"行为式探针 + 决策危害"必须从 RQ1 的"备选"**升级成主判据本身**，口头概率降为纯辅助。否则 RQ1 会被"你给它偏差数据、它给偏差答案"一句话打死。

---

## 6. 下一步（一个需要拍板的岔路）

pilot 说明当前 substrate 只撑得起较弱的 claim。往哪个方向定 headline，决定论文的野心和工作量：

- **A（推荐）收紧到"当场版"**：headline 改成"当 AI 依据被删失的记忆做自我估计时，估计被系统性扭曲、并因果地损害决策"。诚实、当前 substrate 已支持、pilot 已验方向、工作量可控。
- **B 升级 substrate 冲"持久版"**：上跨会话持久记忆／多轮内化，支持更强的"记忆固化持久扭曲自我认知"。野心大、更抗"复读"质疑，但工程重、有跑不出持久效应的风险。
- **C 两者都要**：主论文走 A，再加一节持久性初步探索（B）作为 future work。

还没跑的下一测：①**行为式探针**（把"报概率"换成"在做／不做之间下注"，看是否也随可见成功率变）；②**关键的删失测试**（当"看得见的成功率"和"真实能力"不一致时，模型跟哪个）。

---

## 7. 诚实边界（证据等级）

- **本周 pilot = 测量流程验证（合成卡）**，不是主实验、不进主实验结论；它只回答"测量工具有效吗、前提成立吗"，答案是"是，但暴露了复读风险"。
- 主实验的数据契约要求**全程零 AI 合成**：题目用公开竞赛原题、判分用官方测试／精确匹配、难度用模型真实通过率、历史用被测模型真跑的日志——本周合成卡仅限"流程验证"这一个例外用途，已在此显式标注。
- 整条线诚实新颖度约 55%（取决于执行），且高度依赖"对自己 ≠ 对世界"这个对照做扎实、以及行为式探针把"复读"和"真扭曲"分开。
- 本公开包不含任何 API 凭证、私有 prompt／response 正文或付费服务密钥。
