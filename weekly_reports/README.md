# Weekly Reports

This is the canonical public index for the full weekly research sequence.
Weeks 1--5 are preserved from the predecessor memory-consolidation program;
Week 6 is the transition into AgentMembrane; Weeks 7 onward track the current
AgentMembrane program. New weekly reports are prepared, validated, and committed
here; a staging or handoff copy does not count as published. See
[PROCESS.md](./PROCESS.md) for the exact workflow and release checks.
