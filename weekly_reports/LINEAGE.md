# Weekly report lineage

The weekly sequence previously crossed two local repositories and several
staging directories. It is preserved here to give readers one stable index.

- Weeks 1--5 originated in
  [`memory_consolidation_small_pilot`](https://github.com/heaven999b/memory_consolidation_small_pilot).
- Week 6 was drafted in that repository while its code and result summaries
  moved to AgentMembrane; the weekly package itself had not been committed.
- Week 7 was the first weekly package committed in AgentMembrane.
- Week 8 existed only in local staging and a Cloud handoff package before this
  consolidation.
- Week 9 was first published in AgentMembrane and remains an interim,
  diagnostic-only report while the three-tier formal runtime is repaired.

The imported files retain their historical claims and dates. Sanitization only
replaces machine-local paths and credentials-related routing details; it does not
change result numbers or evidence labels.
