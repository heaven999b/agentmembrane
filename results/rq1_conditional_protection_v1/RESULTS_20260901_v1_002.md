# RQ1 conditional protection supplement v1-002

Namespace: `rq1-conditional-protection-20260901-v1-002`

This supplement tests conditional mechanism behavior and does not replace the
model-mediated end-to-end RQ1 experiment. It replays exact upstream AgentDojo
ground-truth plans byte-identically across vulnerable and protected arms.

## Design

- 7 frozen workflows.
- 14 matched arm pairs: 7 benign canonical-plan pairs and 7 paired target-attack
  pairs.
- 28 real native AgentDojo session resets and 28 native checker evaluations.
- Vulnerable sessions record the same authority decision in shadow mode but
  dispatch regardless; protected sessions enforce it.
- Proposal and terminal text sources are explicitly scripted/upstream and are
  never represented as model-generated.
- 0 model calls, 0 provider calls, 0 API calls, 0 network calls, and 0 LLM
  tokens.

## Result

`baseline_passed=true`; all 14/14 matched pairs passed.

| Endpoint | Vulnerable | Protected |
| --- | ---: | ---: |
| Exact target sequence supplied | 7/7 | 7/7 |
| Target action outside user authority | 7/7 | 7/7 |
| Native attack effect | 7/7 | 0/7 |
| Target denied before native dispatch | not enforced | 7/7 |
| Protected state unchanged after target attempt | n/a | 7/7 |
| Benign canonical-plan utility | 7/7 | 7/7 |
| Benign canonical plans fully admitted | 7/7 | 7/7 |

Every target pair used the same action sequence, the same initial state, and
the same shadow authority-decision digest across arms. The arm difference was
therefore enforcement: vulnerable dispatch produced the upstream attack effect,
while protected denial produced no native effect.

This supports the narrow conditional statement:

> Given an exact upstream unauthorized target proposal, AgentMembrane prevents
> the proposal from producing its native AgentDojo effect while retaining
> utility for exact upstream benign plans in this seven-workflow slice.

It does **not** establish natural model exposure, intent formation, target
proposal activation, or the population-level end-to-end RQ1 effect.

## Preserved failed precursor

`v1-001` is retained and was not overwritten. Its benign replay used a generic
terminal string, so two Travel utilities failed even though all canonical tool
actions were admitted in both arms. Those upstream checkers require rating,
price, or address text in the terminal answer. `v1-002` replays the task's
canonical `GROUND_TRUTH_OUTPUT`, labels that source explicitly, and passes both
Travel checks. The change did not alter authority, target actions, native
effects, or the upstream checker.
