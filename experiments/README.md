# Experiment artifacts

This directory contains public, frozen study definitions: protocols,
preregistrations, small profiles/configs, builders, and preflight receipts.

It does not contain raw prompts or responses, per-case records, licensed dataset
text, caches, local routes, credentials, or resumable run state. Those remain in
the private workspace. A completed public run belongs under `results/`, with a
manifest and an executable audit command.

Canonical construct identities and cross-directory links are in
[`studies/registry.json`](../studies/registry.json).
